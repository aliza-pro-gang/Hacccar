VoiceShift — Boy to Girl Voice Changer
A browser-based voice changer made with plain HTML, CSS and JavaScript.
Features
Microphone recording
Boy → Girl style pitch effect
Pitch control from +2 to +10 semitones
Brightness control
Voice speed control
Girl / High Girl / Natural presets
Audio playback
WAV download
No backend required
Audio processing happens locally in the browser
Run locally
Open index.html in a modern browser.
For microphone access, a local server is more reliable:
python -m http.server 8000
Then open:
http://localhost:8000
GitHub Pages
Create a GitHub repository.
Upload index.html, style.css, script.js, and README.md.
Open repository Settings → Pages.
Select the main branch and root folder.
Save and open the generated Pages URL.
Important
This is a lightweight browser voice effect, not a professional AI voice-conversion model. Pitch shifting and EQ can change the character of a voice, but they do not guarantee a natural human-like female voice.
For a more realistic AI conversion later, a server-side or specialized voice-conversion model would be needed.
